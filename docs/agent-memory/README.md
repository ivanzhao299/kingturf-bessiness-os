# KingTurf Agent Memory

This directory is the project-local, human-readable source of truth for long-running Agent Studio, Codex, and other-agent work.

- Keep `project-state.md`, `task-sequence.md`, `decisions.md`, `sessions.md`, and `handoff.md` here.
- Append progress, decisions, validation evidence, commits, local/remote SHAs, blockers, and next steps; do not erase history.
- Every entry must include an ISO timestamp, task ID, runner/agent, branch/worktree, and evidence path or command.
- Agent Studio runtime memory may index this directory, but must not be the only copy.
