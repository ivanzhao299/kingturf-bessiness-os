# 核心信念（智能体优先的操作原则）

> **争议的裁决依据**。当"该不该这么做"出现分歧时，回到这份文件，而不是聊天记录。方法论来源：OpenAI《Harness engineering》（2026-02-11）最佳实践 + 本项目三轮评审沉淀。

## 通用原则（12 条）

1. 人类掌舵，智能体执行。人类不直接贡献代码行——负责目标、边界、验收。
2. 工程师的工作是设计环境、明确意图、构建反馈回路，而不是逐行编码。
3. 上下文是稀缺资源；给地图，不给说明书（入口文件 ≤100 行，细节下推）。
4. 智能体在运行时看不到的东西，对它来说不存在——一切关键信息进仓库。
5. 强制不变量，不微观管理实现：规定"什么不许发生"，不规定"用什么库怎么写"。
6. 中央强制边界，本地允许自主表达：正确即可维护即达标，不追求人类风格偏好。
7. 纠错成本低、等待成本高：短生命周期提交 + 最小阻塞式门禁。
8. 技术债是高息贷款：小额高频偿还，禁止攒成大爆炸重构。
9. 遇到卡点先问："缺的是什么能力？如何让它既清晰可读又可强制执行？"
10. 人类品味要持续被捕捉——写进文档，或直接编码进工具（linter/结构测试）。
11. 交互式决策必须落盘：确认过但不写进仓库的决策等于没做。
12. 改造存量项目时，重构不改变业务行为；行为变更必须显式登记并单独提交。

## 本项目特有取舍（裁决先例）

| 信念               | 裁决                                                                                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 偏好"无聊"的技术   | 零框架路线：原生 `node:http` + 原生 DOM + 原生 CSS，运行时依赖仅 `pg`（ADR-0001）。新增依赖前先问"能否内化"（R6）                                                |
| 允许重实现功能子集 | 手写校验器/迁移 CLI/表单引擎均属有意为之；行为可控、100% 可测的小实现优于适配不透明上游（§1.3）                                                                  |
| 边界处解析数据形状 | SQL 一律参数化；前端 innerHTML 必过 `sanitizeBusinessDocumentHtml`；运行时边界校验正在补（TD-BOUND-001）                                                         |
| 安全默认拒绝       | 授权 default-deny + SQL 级 DataScope（ADR-0004）；会话不透明 token + scrypt（ADR-0003）；不引入 JWT                                                              |
| 业务对象不可变     | 报价/订单等台账只追加修订、不改历史（ADR-0007/0009/0010）；审计与事件走事务 outbox（ADR-0006）                                                                   |
| 重构红线           | R1 行为守恒、R2 变更显式登记单独提交、R3 先护栏后动手、R4 不顺手修、R5 存疑不删、R7 不藏信息、R8 每步可回滚（全文见 `docs/HARNESS-RULES.md` §9，竣工后迁入本节） |
| 反模式警戒         | 先动手后补计划、全仓大爆炸、重构混行为变更、无护栏重构、覆盖率门禁形同虚设、巨型入口文件、决策只留对话（清单全文见规则 §12）                                     |

## 术语

harness＝围绕代码库的环境/约束/反馈回路总和；不变量＝可机械检查的约束；结构测试＝校验架构约束而非运行时行为的测试；地图 vs 百科＝入口是目录、深层真相在各自文档。完整术语表见 `docs/HARNESS-RULES.md` 附录 D。
