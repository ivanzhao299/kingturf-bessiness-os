# ADR-0014：前端组件层与框架（Preact + Signals 组件基座）

日期：2026-11-19。状态：**已批准**——U0 规范落盘随本 ADR 落地；U1 基座原语起按[UI 基座计划](../tasks/ui-foundation-program-2026-11-19.md)逐批推进、逐检查点（UI-CP1..UI-CP5）停报。授权链：2026-11-19 项目所有者第四次人裁（项目定位「实习生 AI coding 练手」；批准 U0 立项、TD-UI-001、本 ADR 允许轻量框架、U2 试点=governance 及一切必要操作；解除 core-beliefs #8「禁止大爆炸重构」约束，仅限本计划）；主协调代理裁定框架选型与迁移策略（见 §决策 1/5）。

## 背景

2026-11-18 系统管理优化计划人工验收发现：governance 子页经 B1 子路由化后仍是「卡片墙堆叠」——子路由只是让 11 个异质治理面可寻址，每页本体依旧是全量列表+按钮组的原始堆叠，没有页面解剖（anatomy）范式。放大到全站前端，存在五个缺口：

1. **无 UI 基座**：无可复用的组件原语层（表格/抽屉/表单区/状态徽章等），每个域手写一遍 DOM 样板；
2. **dashboard 范式泄漏**：工作台把仪表盘式卡片布局带进本应是「主列表+操作」的业务页，两类页面范式混用；
3. **渲染领域耦合**：渲染逻辑与领域状态（fetch/分页/选中/校验）揉在同一批过程式函数里，视图行为无法独立测试；
4. **无设计 tokens**：色彩/间距/字阶/圆角/阴影散落各处 CSS，无单一取值来源，暗色模式无处安放；
5. **组件层缺失**：占位 `packages/ui` 已在 D3（TD-HYG-001）清理，web 没有组件层可消费。

第四次人裁在此外将项目定位调整为「实习生 AI coding 练手」：允许以学习/演进为目的引入轻量框架，授权主协调代理全权执行全项目设计/开发/UI/UX；监督模式=主协调+哨兵+检查点+绝对止损（任何 FAIL 停止即报，不得自行续修）。

## 决策

1. **框架 = Preact + @preact/signals**（主协调已裁，不再议）：
   - 仅此 2 个新运行时依赖，落 `packages/ui`（重建；与 D3 清理的旧占位包无继承关系）；零新构建工具链——Vite/esbuild 既有链路直接编译，仅加 tsconfig 配置 `"jsx": "react-jsx"` + `"jsxImportSource": "preact"`；
   - signals 提供细粒度响应式，与组件层状态（选中集/分页游标/表单校验态）天然契合，无 VDOM 级全局重渲染。
2. **组件层位于 `packages/ui`**：设计 tokens + 原语组件 + 类型化 props API；`apps/web` 经 `web→ui` 工作区边消费（U1 起真实建立）。
3. **四类页面解剖模板**（迁移目标范式，逐页对表验收，定义见计划 §3）：
   - **列表页** = 主列表（DataTable：列定义/排序/行选择）+ 行级操作 + 批量操作栏；
   - **详情页** = 主从布局或详情抽屉（DetailDrawer：焦点陷阱/Esc/aria）；
   - **配置页** = 结构化表单（FormSection）+ 版本侧栏；
   - **仪表盘页** = 指标卡 + 钻取（不与列表页范式混用）。
4. **设计 tokens**：`packages/ui/src/tokens.css` 以 CSS custom properties 定义色彩/间距/字阶/圆角/阴影五族 token，暗色变量预留（`[data-theme="dark"]` 作用域占位）；tokens 是组件样式的唯一取值来源，组件 CSS 引用变量不写死值。
5. **分域增量迁移，与旧 vanilla 视图共存**：迁移策略 = 分域彻底重写（域内一次性换成组件层实现），**不是**全站一次性大爆炸；旧 vanilla 视图未被迁移前保持原样零改动。顺序：U2 governance 试点 → U3 commercial+CRM（捆绑 TD-WEB-001 巨石债）→ U4 门户统一。
6. **分页契约复用**：DataTable 接入既有 cursor 分页契约（limit 1-100 默认 50 + opaque cursor → `{items, nextCursor}`，TD-API-003/B2 已立），组件不发明新分页模型。
7. **表单语义兼容**：FormSection 封装沿用 `apps/web/src/shared/forms.ts` 的校验/敏感词二次确认语义，组件化不改变校验规则本身。

## 替代方案（已拒绝）

- **纯 vanilla 组件层（零依赖继续手写）**：五缺口的根因恰是无组件模型的手写 DOM——渲染/状态/事件样板在 20+ 域重复，人工验收已证此路线产出卡片墙；维持现状等于拒绝本 ADR 要解决的问题——拒绝。
- **Lit**：Web Components 与本仓 TypeScript-first、Vite SPA、vitest 行为测试链路耦合弱；模板字符串难以提供类型化组件 API；Shadow DOM 与全局 tokens CSS 体系冲突——拒绝。
- **Vue**：单文件组件需 vue 编译器插件（SFC），违背「零新构建工具链」；模板编译期响应式与已裁定的 signals 维粒度响应式选型不同；运行时体积大于 Preact——拒绝。
- **React**：运行时体积与心智成本对本项目过重；Preact 提供同构组件 API 且与 signals 原生集成——拒绝。
- **全站一次性重写**：即使 #8 已对本计划解除，一次性替换全部视图仍不可回滚、不可分域验收；分域重写每域独立提交与检查点（UI-CP 序列）——拒绝。

## 后果

- **新依赖边登记**（`ARCHITECTURE.md` §1 已同步）：`packages/ui → {preact, @preact/signals}`（外部运行时依赖，全仓外部运行时依赖由 1 个 pg 增至 3 个）；`apps/web → packages/ui`（工作区边）。DAG 保持：ui 不依赖其余 packages，也不被任何 package 反向依赖。
- **R6（优先内化）前端例外**：core-beliefs「零框架路线、运行时依赖仅 pg（ADR-0001）」的前端半区由本 ADR 显式突破并登记；后端半区不变。
- **被迁移域的 DOM 级行为测试随域重写**：迁移政策 = 每域「行为重写 + UX 升级」双标签，域内既有 DOM 断言测试同批更新（经第四次人裁批准，见计划 §5）；未迁移域测试零改动。
- **core-beliefs #8 注记**：本计划的分域重写经 2026-11-19 人裁解除大爆炸禁令，由本 ADR 治理；其余场景 #8 保持。
- **启动预算门禁继续生效**（登录入口 ≤12KB JS gzip）：组件层必须随各域 chunk 懒加载，`#/ui-kit` 演示页不得进入登录入口。
- **风险**：vanilla 与组件层双范式共存期的包体与维护成本上升；以 U2 试点（UI-CP2）验证收益后再推进 U3，止损点前置于每个检查点。

## 验收要点

- **U1（=UI-CP1）**：8 原语行为测试红→绿全清单；tokens.css 覆盖五族 token；`#/ui-kit` 仅持 `authorization:read` 可见；`pnpm why` 证明仅 2 个新运行时依赖；结构门禁纳管 `packages/ui`；完整 `pnpm ci:local` 0。
- **U2（=UI-CP2）**：governance 三页（身份/组织/审计）解剖合规对表 100%；授权角色操作 5→2 步度量达标；域内测试同批重写并双标签注明。
