# Batch6 多岗位验收执行计划

每个场景固定最终 SHA、配置、隔离 schema、输入来源、预期/实际结果、业务对象 ID、审计/outbox、独立对账、失败处理、操作员、业务负责人和独立复核人。

| 岗位        | 首批场景                                   | 主要拒绝/对账                 | 责任角色            |
| ----------- | ------------------------------------------ | ----------------------------- | ------------------- |
| 销售        | 客户、商机、技术需求、报价审批、合同、订单 | 越权字段、金额与报价基准      | 销售主管            |
| 技术        | 规格、方案、BOM manifest、工程变更         | 多有效BOM、版本漂移、替代料   | 技术负责人          |
| 采购        | PO、部分收货、批次、退货                   | 4+2+4累计、重复收货、库存对账 | 采购主管            |
| 计划        | 订单需求、MRP、工单下达                    | 非法订单来源、BOM冻结         | 计划负责人          |
| 生产        | 工单、领退料、报工、成品卷                 | 7+7库存竞争、单位/数量对账    | 生产主管            |
| 质量        | 检验、隔离、放行、追溯                     | 未放行发运、批次/投诉关联     | 质量负责人          |
| 仓库/物流   | 放行、POSTED出库、分批发运、POD、退回      | O/D/P累计、重复过账、取消回退 | 仓库主管/物流负责人 |
| 财务        | 应收、收款、核销、成本、利润               | 独立金额/成本/回款基准        | 财务负责人          |
| 管理层      | 驾驶舱、风险、订单成本利润                 | 估算/实际/应计边界            | 经营负责人          |
| 管理员/运维 | 授权撤销、附件隔离、恢复、告警             | 跨组织拒绝、备份哈希、RPO/RTO | 运维负责人          |

任何场景缺少真实岗位签署、独立对账、恢复/回滚证据或依赖未批准规则，都保持 NOT_COMPLETED。当前试运行仍 NO_GO。
