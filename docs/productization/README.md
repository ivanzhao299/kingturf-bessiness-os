## 证据和状态规则

实现 I、自动测试 T、人工验收 H、部署 D、真实持续使用 U 分列。历史 SHA 的自动测试或人工演练，只能支持当期已证范围；全套测试通过也不证明无业务缺陷。A–F 是能力处置分类：A 可保留、B 体验优化、C 正确性缺陷、D 结构重构、E 必需缺失、F 延后；同域可以有多个子能力，不强迫整个模块只贴一个标签。证据不足标“待核”，不强判 A。

治理事实顺序为当前代码与真实测试、有效人工决策、同版本运行证据；日期较新的文字不能取代更强的实证。历史文件保留原样。Harness 已归档于 [completed 施工图](../exec-plans/completed/harness-migration.md) 和 [归档材料](../exec-plans/completed/harness-2026-10-21.md)；AGENTS、ARCHITECTURE、CI 中部分 active 路径及“尚未竣工”是旧快照。本工程遵守现行常驻 DAG、参数化 SQL、会话、事务、审计、门禁与行为变更登记规则，不恢复已结束施工的旧冻结，也不自行废除安全限制。
