## A1 制造成本精度与舍入

**业务含义。** 数量和分钟是生产计量，金额是成本、报价和利润的输入。分项存储值必须能独立复核，总额不得脱离已存分项产生隐含差额。

**推荐契约。** 输入数量/分钟最多 6 位并沿用现行 trunc6；中间乘法、汇总和汇率换算使用确定性定点十进制，不经过 JavaScript `Number`；每个金额分项量化至 Q6，持久化后由分项相加形成总额；负数和冲销按 HALF_AWAY_FROM_ZERO，`-0.000000` 归一为零。币种小数、FX 来源/方向/时点和税基必须随计算版本保存。

**反例。** 不能先把未量化分项相加后独立舍入总额，再删除一致性约束；不能用浮点误差、扩大容差或改断言掩盖 `planned_total` 不一致；不能把负冲销当作正向费用。

**影响与实施。** 新 run 保存 `calculation_version`、舍入模式、币种和 FX 依据；历史 run、已批准报价和利润快照只读。获批后先实现纯定点计算契约和正/负/tie/FX 边界测试，再改成本服务和数据库约束，最后做报价、审批、利润回归。

**验收与回滚。** 独立基准逐项核对分项、总额、负值、跨币种和重复重放；任何约束失败必须无 run、审计或 outbox 残留。回滚到上一计算版本时保留旧 run，不重算覆盖历史；新版本停止写入后仍可读取旧版本。

**最小审批项。** `trunc6` 是否保留、Q6 是否适用于全部币种、HALF_AWAY_FROM_ZERO 或 HALF_EVEN、FX/税基权威来源、历史单据是否完全冻结。

## A2 成本驳回后的不可变修订

**业务含义。** 驳回意味着当前成本证据不能用于关单或发运；修订必须留下新证据，不能改写原驳回记录。

**推荐状态机。** `CALCULATED → APPROVED|REJECTED`；只有“当前、未关闭、REJECTED”允许创建 `r(n+1)`。新 run 保存 previous run、政策/BOM/价格快照、源事务截止点和公式版本，重新计算后必须由不同于申请人的审批人批准。只有最新 current run 为 `APPROVED` 才解除关单和发运门卫；旧 APPROVED 不回落兜底。首版不增加待审撤回； APPROVED/CLOSED 的更正另走调整单。

**并发与幂等。** 命令键绑定租户、工单、`expectedCurrentRunId` 和规范化意图；同键同输入返回原结果，异输入返回 409。修订、审批、驳回、关单和发运按工单→当前 run 的稳定顺序加锁，并在锁内重读 current；竞争只能保留一个 current candidate，失败整笔回滚。

**影响与实施。** 新迁移只增修订关联、依据快照、复合约束和 current 投影；旧 run 自动成为 `r1`，未知 BOM 标 `LEGACY_UNVERIFIED`，不回填 latest。API 和前端新增修订时间线、差异、原因和只读历史。报价、合同、订单和工单引用精确 run，不因修订重写历史商业金额。

**验收与回滚。** 覆盖拒绝→修订→异人批准→关单、双并发修订、撤权重放、旧版审批、晚失败回滚和跨租户拒绝。回滚只停止新修订入口并保留已写历史；不得删除唯一约束或更新旧 run。

**最小审批项。** 原申请人能否再次提交、关闭后是否允许调整单、current 唯一约束形式、批准/拒绝错误合同、历史 run 的 `r1` 回填范围及迁移窗口。

## A3 发运与仓库出库

**业务含义。** 发运放行是商业/质量条件许可；仓库 POSTED 是实物离库和库存减少；物流发车、签收和退回是后续事实，不能由创建发运单隐含扣库。

**推荐契约。** 分别记录批准可发 `A`、创建发运 `C`、实际出库 `O`、实际发车 `D`、签收 `P`。仓库授权岗位在 `POSTED` 事务中锁定订单额度、放行行和库存资源，重新校验质量/信用/合同门禁，写唯一负库存移动、额度消耗、审计和 outbox；发运创建不扣库，首版不预留库存。允许分批，累计 O/D/P 不超过对应订单行/放行行额度；同一意图幂等，竞争请求明确冲突。`CONFIRMED` 发车前可取消并释放未发车分配；已 POSTED 不直接恢复库存，退回走检验和补偿入库；`CANCELLED` 不可再次发车。

**影响与实施。** 需要出库头/行、发运分配、POD、退回收货和额度事件的关联模型，逐行绑定订单、批次、卷号、单位换算和源移动。物流岗位不能自动获得库存过账权限。历史无数量关联运单标 `LEGACY_UNRECONCILED`，不猜测补扣库。

**验收与回滚。** 覆盖 10=4+2+4、7+7 并发超发、重复 POSTED、跨仓/批/组织、质量隔离、信用变化、取消、部分签收、实物退回和补发；独立对账 `库存余额=正负流水`、`O/D/P≤允许量`。回滚只关闭新出库/分配入口并保留已过账流水；不得删除历史移动或自动恢复库存。

**最小审批项。** 方案 A/B、实际仓库岗位、是否需要时效 reservation、单位/卷拆分和公差、例外批准人、退回后额度是否恢复。

## A4 BOM 版本固定

**业务含义。** 草稿工单可评估方案，正式 RELEASED 才代表生产执行承诺；执行、领料、报工和成本必须解释同一多层物料依据。

**推荐契约。** 在 RELEASED 事务中固定 `releaseAt`、`knowledgeAsOf`、产品/路线/BOM 版本、产出基数、单位、损耗、替代料和 manifest hash。MRP、生产和成本均引用该不可变 manifest；多个同生效候选拒绝自动排序，必须由有权技术岗位显式选择。释放后工程变更走变更单/追加 manifest；已领料或报工部分不得静默切换版本；历史缺失版本标 UNKNOWN。

**影响与实施。** 新迁移补工单 manifest/hash 和逐层版本引用，旧工单只读兼容；API 返回冻结依据和变更链，前端显示版本漂移、替代料和损耗。新计算不得 fallback 到 latest published BOM。

**验收与回滚。** 覆盖释放并发、两层非 1 基数、损耗/替代料、释放后发布新 BOM、已领料工程变更、跨公司拒绝和晚失败回滚；旧工单仍可按历史快照解释。回滚停止新冻结入口并保留已冻结 manifest，不删除历史版本。

**最小审批项。** 工厂时区、创建还是 RELEASED 冻结、释放后变更角色、替代料批准人、已领料/报工后的变更边界、旧 UNKNOWN 工单处置。

## A5 订单实际利润

**业务含义。** 报价毛利、政策价制造估算、已归集实际费用和最终结算利润是不同状态，不能用一个数字覆盖未完成归集。

**推荐契约。** 分列报价估算、标准/计划成本、实际制造（当前为政策费率计价时明确标注）、物流、佣金、质量/返工、销售费用、应计和冲销。每条成本带 `sourceType/sourceId/sourceVersion`、原币/税基、汇率快照、发生/确认时点和 `ESTIMATED/ACCRUED/ACTUAL/REVERSED` 状态；缺失不填零。只有必要来源完成、独立对账并通过截止检查才允许标记经营利润 `COMPLETE`；法定收入、税务和会计凭证仍由外部财务系统负责。

**影响与实施。** 先建立来源矩阵和订单成本快照，再实施共享工单分摊、物流/佣金/质量费用接口；同一来源只能归集一次，晚到费用以新版本和反向关联记录，不覆盖旧快照。历史订单保持原报价毛利语义并标估算/未知。

**验收与回滚。** 覆盖多币种、部分交付/回款、政策价≠采购价、共享工单分摊、佣金冲回、质量损失、物流实票替代应计、退回和晚到费用；未完整归集不得显示最终全成本。回滚停止新利润快照，保留已生成来源和旧快照，不删除外部对账证据。

**最小审批项。** 收入确认事件和税基、材料实际估值（政策价/FIFO/移动平均）、物流/佣金/质量权威来源、共享工单分摊、晚到费用、关单后追补责任。
