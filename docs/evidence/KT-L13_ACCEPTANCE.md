## Source-to-Stock 主链路

系统已提供租户隔离、字段授权和审计事件覆盖的供应链闭环：

1. 建立供应商及联系人、账期、币种和质量评分；
2. 将供应商准入固定到已发布物料版本，并记录有效期、MOQ、交期和审核证据；
3. 创建并签发 RFQ，RFQ 行签发后不可修改；
4. 登记供应商报价及逐行价格/承诺交期，报价和报价行写入后不可修改；
5. 创建并签发采购订单，订单内容和行项目签发后冻结；
6. 按采购订单行分批收货，同时建立供应批次、收货行和 `RECEIPT` 库存移动；
7. 库存余额只从不可变移动台账汇总，出库和调整不能造成批次库位负库存。

## 204 真实业务场景

| 证据       | 结果                                                             |
| ---------- | ---------------------------------------------------------------- |
| 供应商     | `SUP-KT-YARN-001`，ACTIVE，12000D 草纱物料版本已批准准入         |
| RFQ        | `RFQ-KT-YARN-2026-001`，ISSUED，询价 5,000kg                     |
| 供应商报价 | `SQ-KT-YARN-2026-001`，12.5 CNY/kg，规范哈希有效                 |
| 采购订单   | `PO-KT-YARN-2026-001`，5,000kg，总额 62,500 CNY，状态 RECEIVED   |
| 收货与批次 | `GR-KT-YARN-2026-001` / `LOT-KT-YARN-20260920-A`，入库 `RAW-A01` |
| 库存余额   | 5,000kg，由一笔不可变 `RECEIPT` 移动推导                         |

重复运行演示种子不会重复生成该供应链。204 PostgreSQL 反向测试确认：供应商报价篡改、已收货采购行篡改、库存移动篡改和造成 -1,000kg 负库存的出库均被数据库拒绝。
