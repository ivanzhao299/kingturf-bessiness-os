询价单根行没有供应商字段，创建或签发询价单无供应商状态可校验。将供应商关联到询价单的操作是登记该供应商的报价。

| ---------------------------------- | ------------------------------- |

| `POST /purchase-orders` 新建采购单 | 409，要求启用的供应商           |
| 签发此前已建的草稿采购单           | 200（待登记 `proc5-2`）         |
| 对此前已签发的采购单收货           | 201，两笔各收 4、2 后库存为 6   |
| 取消此前已签发且未收货的采购单     | 200                             |
| 物料准入审核                       | 200                             |

相同的登记报价和新建采购单请求在供应商启用时均为 201。本批沿用既有规则。暂停与停用确认框据此说明对新报价、新订单和既有订单的影响。
