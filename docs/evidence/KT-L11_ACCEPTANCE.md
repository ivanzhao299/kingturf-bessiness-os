## 权限和下钻

- 新增独立 `executive-dashboard:read`；所有聚合先执行该权限的 DataScope。
- 指标和下钻还要求来源模块权限：销售、报价、核销、应收、风险和佣金分别裁剪，驾驶舱不会扩大来源可见范围。
- API 单元测试以 TEAM 驾驶舱范围验证：有订单/风险权限时仅返回相应指标及下钻，无 `ar:read` 时应收指标和逾期清单均不返回。
- 订单贡献可下钻订单号、金额和固定报价毛利；风险责任可下钻订单、严重度、分数、任务状态和责任人。
