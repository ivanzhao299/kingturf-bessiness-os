## 5. 本次上线了什么

对使用者可见：

- 治理、商机、客户、供应链、生产（物料与 BOM）五个域的 Preact 控制台交互增强。
- 可排序列的表头不再是浏览器默认的灰色立体按钮。
- 手机宽度下页面不再横向溢出，主从布局折为单列。
- 治理域「在职」状态徽章不再是繁体「在職」。
- 「危险」语义的状态徽章（已驳回、已逾期等）显示为红色，不再是灰色。
- 抽屉打开后键盘焦点进入抽屉，Tab 不会跑到抽屉外，关闭后焦点回到触发按钮。

不可见但更重要：

- 采购订单详情接口不再返回 500（此前对任何采购单都失败）。
- API 对未预期异常写入一条可定位的失败记录（类型、系统错误码、栈帧；不含异常消息）。
