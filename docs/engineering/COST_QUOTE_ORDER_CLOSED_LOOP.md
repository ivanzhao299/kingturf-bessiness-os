# 成本、报价、合同与订单闭环

## 产品边界

规格成本矩阵负责回答“该产品规格在某一价格口径和日期下，每平方米成本是多少”；成本决策负责把该结果绑定到一个最终技术方案和商机；报价、审批、签发、合同与销售订单继续使用现有不可变版本链。任何对外报价都不得直接引用一个会被后续编辑覆盖的矩阵。

## 价格优先级与证据

每个因子必须保留耗用量、单位、含税回退价、税率、来源名称、来源编号或链接、生效日期和说明。解析顺序如下：

1. 关联物料最近一张已下达、部分收货或已收货采购订单行；它代表已经形成业务约束的采购合同价。
2. 关联物料最近一张尚未过期、且来自有效供应商的报价行。
3. 有明确发布日期和链接的市场公开参考价。
4. 经成本部门确认的企业计划成本基准。
5. 临时手工录入仅用于测算，必须写明来源；有耗用量但价格为零时，系统拒绝核算。

系统预置值是 2026-08-28 的可编辑初始化基线，不是永久标准价。草丝树脂、丁苯胶乳、人工和电力分别引用公开市场或统计口径；底布、色母、包装、制造费用以及各项预留因企业规格和会计政策差异较大，明确标为企业初始计划基准。正式报价前应优先绑定采购物料并由成本专员复核。

## 角色分工

| 角色                             | 责任                                                 | 不应执行的操作                   |
| -------------------------------- | ---------------------------------------------------- | -------------------------------- |
| 采购专员                         | 维护供应商、询价、有效报价、采购订单和合同附件       | 不直接修改已冻结报价成本         |
| 成本测算专员 `KT_COST_ANALYST`   | 维护规格因子、来源与企业定额；核算并绑定最终技术方案 | 不审批或签发自己的报价           |
| 报价编制专员 `KT_QUOTE_EDITOR`   | 在同一商机下选择成本决策、销售政策和技术方案生成报价 | 不绕过成本来源或审批门禁         |
| 报价审批专员 `KT_QUOTE_APPROVER` | 核验毛利、折扣、例外理由和政策结果                   | 不改写已提交报价内容             |
| 报价签发专员 `KT_QUOTE_ISSUER`   | 签发并冻结对客报价快照                               | 不修改已签发快照                 |
| 合同、信用与订单岗位             | 完成信用决策、合同修订与签署，并由已签发报价创建订单 | 不以未签发报价或过期信用决策下单 |

## 数据流与门禁

```text
供应商报价 / 采购订单 / 市场基准
                ↓
规格成本因子 → 含税或未税成本计算（不可变因子轨迹）
                ↓
最终技术方案 + 商机 + 已发布企业成本规则
                ↓
报价成本决策 → 销售政策评估 → 报价编制 → 审批 → 签发快照
                ↓
信用决策 → 合同修订与签署 → 销售订单 → MRP / 生产 / 发运 / 应收
```

进入报价成本池时，系统把每个因子的实际取价来源和金额冻结为 `cost_sheet_decision` 及明细行；报价修订只引用该不可变决策。后续价格变化必须重新核算并形成新的成本决策和报价修订，不能回写旧版本。

## 运营要求

- 成本专员每日关注过期供应商报价和采购物料未绑定项；每周复核市场参考价。
- 报价编制前必须确认矩阵规格与最终技术方案一致，且没有零价因子。
- 报价审批必须查看成本日期、最终来源、成本规则调整和毛利率。
- 采购订单或合同价格与市场基准偏差超过公司阈值时，应由采购和成本共同复核，而不是自动覆盖历史成本快照。
- 订单创建后继续沿用现有报价、信用、合同和签署的不可变引用，保证订单 360 可以回溯到每一个成本因子。
