# 文档操作提示与配置直达

## 用户路径

- 未配置渠道：有 `business-document:configure` 权限的用户可点击“前往发送配置”，直接打开现有连接器配置功能；无该权限的用户明确看到“联系管理员”及配置位置，不出现无权限跳转。
- 草稿、驳回、审核中、归档、未绑定客户、未保存正文：显示具体原因。可管理草稿者可点击“去保存 / 提交审核”，有审批权且文档审核中者可点击“去审批”，定位到当前文档操作区域，不自动执行业务动作。
- 加载失败：提供“重试读取渠道”及“重试加载配置”；配置完成后可“重新检查配置”。每次重新读取服务器状态，不使用过期渠道缓存。
- 配置直达使用当前页面的独立对话框，保留底层文档、正文和修改说明，返回后继续编辑。连接器表单与原管理员配置页共用，保存后局部刷新，不再整页 reload。
- 配置成功但刷新失败时，明确说明“配置已保存，但刷新失败”，避免误导用户重复保存。并发更新仍使用原有 expectedVersion 服务端校验。
